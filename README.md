# 48we 个人性载体首页

正式首页的一次性静态快照。包含首页交互、本机养成调试和 A3 JPG 导出。没有自动同步、发布工作流或任何后台服务。

只包含网页文件，不包含独立向量效果、三维数据收集应用、研究资料或参与者数据。字体、导航图标和网页脚本均已内嵌。

在仓库 Settings → Pages 中选择 Deploy from a branch、main、/(root)，保存后访问 GitHub 给出的 github.io 地址。

为兼容 GitHub Pages 的子目录和静态托管，二级入口使用 ?page= 路径参数，目前显示预留页。页面外观与首页交互保持正式版。

这是固定快照；修改本地项目不会更新该仓库或网站。字体许可见 FONT-LICENSE.txt。
